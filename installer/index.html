Aliro door-lock installer

Flash the Aliro door-lock reader firmware to an M5Stack NanoC6 (or any compatible ESP32-C6 board) over USB, then commission it into Apple Home, Google Home, or Home Assistant as a Matter door-lock over Thread.

Build a $13 tap-to-lock or unlock Matter lock

Connect a M5Stack NanoC6 Dev Kit (about $6) to an M5Stack NFC Universal Unit ($7.00).

About $13 total before tax and shipping.

The result is a virtual Matter-over-Thread door lock. Tap a tested Apple Home Key at the NFC reader, then use the lock state to start an automation. For example, unlock a real lock, open a garage door, disarm an alarm, or run another action.

Aliro is designed for wallet credentials across smart-home ecosystems. Apple Home Key works with this build. A Google wallet key is not yet verified here and depends on Google's Aliro rollout.

The board does not drive a physical lock by itself. Use an automation controller for the real action. Prices can change.

This is development hardware with Matter test attestation. Do not use it as the only control for a door, alarm, or other safety-critical system.

Apple Home refuses the QR

iOS 17.x sometimes rejects a valid Matter test attestation when the paired Thread border router has not published its credentials. Confirm your HomePod mini, second-generation HomePod, or compatible Apple TV is signed in to the same iCloud account as the phone and try again after a minute. If it still fails, use Home Assistant Companion instead.

  1. Open the Google Home app on Android with current Play Services.
  2. Tap + then Set up device → New device.
  3. Choose your home and let Google Home scan for Matter-enabled devices, or scan the QR above directly.
  4. Google Home may show an "uncertified device" warning because the firmware uses Matter test attestation. Some release channels of Google Home refuse test attestation entirely.
Google Home refuses the QR

Google Home's acceptance of test-attestation VIDs is inconsistent between release channels. If it fails here, try Apple Home or Home Assistant Companion. Track the exact error text for a lab-notes entry.

  1. Ensure the Matter and Thread integrations are enabled in Home Assistant and a border router is active.
  2. Open the Home Assistant Companion app on your phone. The web UI cannot start commissioning.
  3. Settings → Devices & Services → Add Integration → Matter (BETA).
  4. Scan the QR code above with the phone.
Aliro-specific credential management

Home Assistant does not yet expose Aliro reader configuration (SetAliroReaderConfig and friends) in its UI. To exercise the Aliro delegate on this device, use matter-server or the Matter shell directly after commissioning. This is expected to improve as Home Assistant's Aliro epic lands.

Something went wrong — factory reset

To reset the device and start commissioning again:

  1. Unplug USB.
  2. Hold the M5 NanoC6 reset button as documented for the bootloader entry sequence.
  3. Reconnect USB and re-run this installer.

A full-chip erase removes any Aliro reader configuration and credential-issuer keys the device held. For a mid-commissioning retry that preserves those, restart the phone app instead of re-flashing.

Before you start

  • A USB-C data-capable cable and an M5 NanoC6 with the Unit NFC (ST25R3916) attached over Grove.
  • Chrome or Edge on macOS, Linux, or Windows (Web Serial API required). Safari and Firefox do not support Web Serial.
  • A Thread border router on your LAN (Home Assistant + SkyConnect / ZBT-1 / ZBT-2, Apple HomePod mini or second-generation HomePod, or Google Nest Hub 2nd gen).
  • Bluetooth on your phone; Matter commissioning runs over BLE.

Remove or reset the lock

  • To remove one Matter service, remove the lock in that service's app. Do not erase the lock while other services use it.
  • For a full reset, keep the lock online. Remove it from every Matter service and let each removal finish. Then use Factory install.
  • Factory install cannot notify a Matter service. If the lock is already erased, remove its stale entry from each app.

Factory install — erase everything

Use this for a first install or recovery. It erases the entire flash. You will lose Matter fabrics, Thread credentials, and Aliro reader configuration.

Choose Update to keep setup on an approved layout. Choose Factory install for a first install, recovery, or a different layout.
